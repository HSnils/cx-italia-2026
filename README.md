# CX Italia 2026 - Event Program PWA

A Progressive Web App displaying the event program for **CX Italia 2026** — Camel Extreme's trip to the Dolomites and Venice (Onsdag–Søndag).

Styling is inspired by the [Camel Extreme](https://www.camelextreme.com/) vibe: dark, metallic charcoal backdrop, black & white mountain imagery, glossy red gradient panels, and gold headings.

## Features

- Progressive Web App (PWA) - can be installed on mobile devices
- Offline support via Service Worker (auto-generated by Vite PWA)
- Responsive design for all devices
- Grayscale background imagery with a dark overlay
- Clean, readable per-day schedule layout
- Built with Vite for fast development and optimized builds

## Program overview

- **Onsdag** — Oppmøte, fly til Milano, busstur til Dolomittene, innsjekk Hotell Piccolo (Selva di Val Gardena)
- **Torsdag** — Valgfri tur fra hotellet
- **Fredag** — Fottur Monte Seura m/zipline, buss til Venezia, innsjekk Pesaro Palace, middag Trattoria da Rino
- **Lørdag** — Lido, Blue Moon Beach, båttur, middag Bakaro
- **Søndag** — Gondoltur, Piazza San Marco/Dogepalasset, hjemreise med SAS SK2698

## Development

### Prerequisites

- Node.js (v18 or higher)
- pnpm (install with `npm install -g pnpm`)

### Setup

```bash
# Install dependencies
pnpm install

# Start development server
pnpm dev
```

The app will be available at `http://localhost:5173`

### Build for Production

```bash
# Create optimized production build
pnpm build

# Preview production build locally
pnpm preview
```

The production files will be in the `dist/` directory.

## Deployment to GitHub Pages

A GitHub Actions workflow (`.github/workflows/deploy.yml`) builds and deploys to GitHub Pages automatically on every push to `main`.

1. Push your code to GitHub
2. Enable GitHub Pages (Settings → Pages → Source: "GitHub Actions")
3. The app auto-deploys on every push to `main`

The site is served under the `/cx-italia-2026/` base path (configured in `vite.config.js`).

## Installing as PWA

Once deployed, users can install the app on their devices:

- **iOS/Safari**: Tap the Share button, then "Add to Home Screen"
- **Android/Chrome**: Tap the menu (⋮), then "Add to Home Screen" or "Install App"
- **Desktop/Chrome**: Click the install icon in the address bar

## Tech Stack

- **Vite**: Fast build tool and dev server
- **Vite PWA Plugin**: Automatic service worker and manifest generation
- **Workbox**: Advanced service worker caching strategies
